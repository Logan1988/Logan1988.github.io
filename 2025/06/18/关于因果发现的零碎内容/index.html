一、比较核心OR难理解的一些问题

1.0 因果发现算法可以分成哪些类型？

大致可以分成三大类：

  • 基于约束的方法
  • 基于函数/得分的方法
  • 混合类型方法

基于约束，constrain based method

是指，典型的算法包括PC系列，FCI系列等

1.1 条件独立性和因果发现有什么关系呢？

首先，条件独立性是概率论中的基础概念，用来描述随机变量之间可能具有的性质，具体是指:

$（若 (P(A=a , B=b \mid C=c) = P(A=a \mid C=c)P(B=b \mid C=c)) ，\对于任意a，b，c都满足上述等式，\则称 (A,B) 关于 C 条件独立，记为 (A \perp B \mid C) ）$

1.2 因果发现算法中常出现哪些假设呢？分别又是哪些类型因果发现算法的基础呢？

1.2.1 假设存在——马尔可夫性

马尔可夫性是概率论、图模型等领域的重要概念，是一个由多个随机变量构成的“系统”或“集合”才可能具有的性质，在不同场景下定义有细分：

在随机过程中，马尔可夫性是指：给定当前状态时，未来状态的条件概率分布仅依赖当前状态，即未来状态与过去状态（历史路径）关于当前状态条件独立（条件是当前的状态）。满足此的过程叫马尔可夫过程，像马尔可夫链（离散时间情况）就遵循，比如天气预测中假设今天天气仅与昨天有关（简化假设）。

马尔可夫性的对象是整个随机过程。只有在随机过程这个系统内，才能讨论该系统是否具有马尔可夫性质。

（下面的记录还是不太准确，还得再确认，下次再弄）

在因果图/概率图领域中：马尔可夫性也叫因果马尔可夫条件 (Causal Markov Condition)是指：一个节点 X 在给定其所有父节点 (直接原因) 的条件下，与其所有非后代节点条件独立。用来判断马尔可夫性成立的数学语言为：
$$
\textbf{【定义】马尔可夫性：} \text{给定一个有向无环图 } G \text{ 以及所有节点的联合概率分布 } P \text{，对于任意两个节点，若 }\\ X_i \text{ 和 } X_j \text{ 被 } S \ \textbf{d-分离} \implies X_i \perp X_j \mid S \text{，则称分布 } P \text{ 满足关于 } G \text{ 的全局马尔可夫性。}
$$
此时，马尔可夫性的对象是一个联合分布P，而因果图就像是状态转移矩阵一样描述了不同节点之间的因果关系，联合分布P中的节点可能就具有马尔可夫性。

在一个因果图中，任何一个变量，在给定其所有直接原因（它的“父节点”）的条件下，都与其所有非后代节点（即不是由它导致的变量）在统计上条件独立。因为有无后性的表述，就取名了马尔可夫性条件。

对象的属性改怎么理解？是和判断的必要条件是等价的吗？虽然对象不等于判断，但是不是可以轻易变化呢？比如 “是对象”就成了判断了能，属性也就变成了必要条件了呢？比如 三角形的属性是有三条边，稍微变一下，是三角形的话，则有三条边。

等一下，马尔可夫性的对象是随机变量吗？也就是说只有对象是一个随机变量的时候，才能具备马尔可夫性这个性质
