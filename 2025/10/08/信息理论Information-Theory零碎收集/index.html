信息论知识点收集

记录信息论中的核心概念和公式，避免重复学习时的遗忘

📚 基础概念

信息量 (Information Content)

  • 定义: 事件发生的不确定性程度
  • 公式: $I(x) = -\log P(x)$
  • 单位: 比特(bit) 或 奈特(nat)
  • 理解: 概率越小的事件，信息量越大

熵 (Entropy)

  • 定义: 随机变量的平均信息量
  • 公式: $H(X) = -\sum_{x} P(x) \log P(x)$
  • 性质: 非负性、对称性、可加性
  • 理解: 衡量随机变量的不确定性

🔗 互信息与条件互信息

互信息 (Mutual Information)

  • 定义: 两个随机变量之间的相互依赖程度
  • 公式: $I(X;Y) = \sum_{x,y} P(x,y) \log \frac{P(x,y)}{P(x)P(y)}$
  • 性质:
    • $I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$
    • $I(X;Y) = I(Y;X)$ (对称性)
    • $I(X;Y) \geq 0$ (非负性)
  • 理解: 衡量知道Y后，X的不确定性减少多少

条件互信息 (Conditional Mutual Information)

  • 定义: 在给定第三个变量Z的条件下，X和Y的互信息
  • 公式: $I(X;Y|Z) = \sum_{x,y,z} P(x,y,z) \log \frac{P(x,y|z)}{P(x|z)P(y|z)}$
  • 性质:
    • $I(X;Y|Z) = H(X|Z) - H(X|Y,Z)$
    • 链式法则: $I(X;Y,Z) = I(X;Y) + I(X;Z|Y)$
  • 理解: 在已知Z的情况下，X和Y还有多少相互依赖

📊 其他重要概念

条件熵 (Conditional Entropy)

  • 定义: 在给定另一个随机变量条件下的熵
  • 公式: $H(X|Y) = -\sum_{x,y} P(x,y) \log P(x|y)$
  • 关系: $H(X|Y) = H(X,Y) - H(Y)$

联合熵 (Joint Entropy)

  • 定义: 多个随机变量联合分布的不确定性
  • 公式: $H(X,Y) = -\sum_{x,y} P(x,y) \log P(x,y)$

相对熵/KL散度 (Kullback-Leibler Divergence)

  • 定义: 两个概率分布之间的差异度量
  • 公式: $D_{KL}(P||Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)}$
  • 性质: 非负性、非对称性
  • 理解: 衡量用Q分布近似P分布的代价

🎯 应用场景

机器学习中的应用

  • 特征选择: 使用互信息选择与目标变量最相关的特征
  • 信息瓶颈: 在保持预测性能的同时最小化表示复杂度
  • 变分推断: 用KL散度作为优化目标

通信理论中的应用

  • 信道容量: 最大互信息决定信道传输能力
  • 编码理论: 熵决定了最优编码长度

📝 学习笔记

常见误区

  • 互信息不是距离度量（不满足三角不等式）
  • 条件互信息可能大于无条件互信息
  • 熵的单位选择会影响数值大小

记忆技巧

  • 熵 = 平均信息量
  • 互信息 = 减少的不确定性
  • KL散度 = 分布间的”距离”
