1. 数字信号滤波的核心原理

涉及的工具：傅立叶变换、卷积、卷积定理、滤波器（kernel，一段特殊的信号）

Key Sight：卷积的最主要关联应用是“滤波”。以后想到卷积，就要想到滤波操作。而卷积滤波的核心理论基础是卷积定理。

1【目标与直觉】

滤波的目标是什么？

  • 核心思想：从原始信号中，筛去不想要的部分，保留特定频率的信号成分。
  • 常见类型：低通/高通滤波

2【核心的概念】

**时域信号：**横坐标是时间的信号

  • 输入信号**x[n]**：等待被处理的原始数据。
  • 滤波器核 h[n]：它是一个定义在时域的短小信号，其结构/形状决定了滤波器的所有特性。例如CNN中的卷积核（图像领域，但非时域信号）、1D的卷积核。

**频域信号：**横坐标是频率的信号，纵坐标的值表示原始信号在该频率上的分量

  • 频率响应 H(ω)：滤波器核 h[n] 在频域的“样子”。精确描述了该滤波器对每一个频率的放大或衰减程度。（根据卷积定理可得）

两个核心操作：

  • 卷积**(Convolution)：一个纯时域的数学运算。它是将滤波器核 h[n] 应用到输入信号 x[n] 上的标准执行过程**。

连续形式：$$y(t)=(f*g)(t) = \int_{-\infty}^{\infty} f(\tau) g(t - \tau) d\tau$$

离散形式：$$y[n] = \sum_{m = -\infty}^{\infty} f[m] g[n - m]$$

  • 傅立叶变换 (Fourier Transform)：连接时域和频域的**“翻译官”或“解码器”。它可以将一个时域信号**（如 h[n]）翻译成其对应的频域表达形式。傅立叶变换的本质是特征分解！

连续形式：$$\mathcal{F}{f(t)} = F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$$

离散形式：$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-i\frac{2\pi}{N} kn}, \quad k = 0, 1, \dots, N-1$$

上述的傅立叶变换表达形式，借用了欧拉公式，将三角函数变换成的指数的形式，本质上是基于任何一段周期信号可以被分解成三角函数的和，即傅立叶级数的表达形式。

3.【卷积滤波操作的“核心理论基础”】

卷积定理 (The Convolution Theorem)：这是所有知识点的“连接枢纽”。

  • 内容：在时域上对两个信号（x[n] 和 h[n]）先进行卷积，再进行傅立叶变换，其结果等价于，在对这两个时域信号各自先进行傅里叶变换（X(ω) 和 H(ω)），再进行进行乘积。
  • 公式：

时域卷积 ⟺ 频域乘积：

$$\mathcal{F}{f(t) * g(t)} = F(\omega) \cdot G(\omega)$$

  • 意义：它告诉我们，一个看似复杂的时域运算过程（卷积），其最终效果可以在频域被一个极其简单的运算过程（乘法）来精确预测。**这使得我们能够通过分析 h[n] 的频域特性 H(ω)，来预知滤波的结果。**这样就对应了前文说的，可以通过分析滤波器在频域上的表达式，确定该滤波器的滤波效果。

4.【实例分析：5点移动平均滤波器 (Case Study)】

目标 (Goal)：实现一个低通滤波器，对信号进行平滑处理。

定义工具 (Define the Tool in Time Domain)：

  • 我们选择了一个简单的“取平均”操作，其对应的滤波器核为 h[n] = [1/5, 1/5, 1/5, 1/5, 1/5]。

执行操作 (Perform the Action in Time Domain)：

  • 通过卷积 y[n] = x[n] * h[n]，得到平滑后的输出信号。

分析与证明 (Analyze via Frequency Domain)：

  • 提问：凭什么说这个操作就是低通滤波？
  • 解码：对 h[n] 进行傅里叶变换，得到其频率响应 H(ω)。
  • 看图说话：H(ω) 的图像呈现出一个巨大的主瓣和多个衰减的旁瓣。
    • 主瓣：在低频区 (ω 接近0) 响应接近1，意味着低频信号能很好地通过。
    • 衰减趋势：主瓣总体趋势是下降的，并在特定频率点（零点）降为0，意味着高频信号被抑制甚至完全滤除。
    • 旁瓣：图像不是单调递减，说明这个简单的滤波器并不完美，会对某些高频有微弱的通过效应。
