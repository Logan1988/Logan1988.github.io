1. 数字信号滤波的核心原理

涉及的工具：傅立叶变换、卷积、卷积定理、滤波器（kernel，一段特殊的信号）

Key Sight：卷积的最主要关联应用是“滤波”。以后想到卷积，就要想到滤波操作。而卷积滤波的核心理论基础是卷积定理。

1【目标与直觉】

滤波的目标是什么？

  • 核心思想：从原始信号中，筛去不想要的部分，保留特定频率的信号成分。
  • 常见类型：低通/高通滤波

2【核心的概念】

**时域信号：**横坐标是时间的信号

  • 输入信号**x[n]**：等待被处理的原始数据。
  • 滤波器核 h[n]：它是一个定义在时域的短小信号，其结构/形状决定了滤波器的所有特性。例如CNN中的卷积核（图像领域，但非时域信号）、1D的卷积核。

**频域信号：**横坐标是频率的信号，纵坐标的值表示原始信号在该频率上的分量

  • 频率响应 H(ω)：滤波器核 h[n] 在频域的“样子”。精确描述了该滤波器对每一个频率的放大或衰减程度。（根据卷积定理可得）

两个核心操作：

  • 卷积**(Convolution)：一个纯时域的数学运算。它是将滤波器核 h[n] 应用到输入信号 x[n] 上的标准执行过程**。

连续形式：$$y(t)=(f*g)(t) = \int_{-\infty}^{\infty} f(\tau) g(t - \tau) d\tau$$

离散形式：$$y[n] = \sum_{m = -\infty}^{\infty} f[m] g[n - m]$$

  • 傅立叶变换 (Fourier Transform)：连接时域和频域的**“翻译官”或“解码器”。它可以将一个时域信号**（如 h[n]）翻译成其对应的频域表达形式。傅立叶变换的本质是特征分解！

连续形式：$$\mathcal{F}{f(t)} = F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$$

离散形式：$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-i\frac{2\pi}{N} kn}, \quad k = 0, 1, \dots, N-1$$

上述的傅立叶变换表达形式，借用了欧拉公式，将三角函数变换成的指数的形式，本质上是基于任何一段周期信号可以被分解成三角函数的和，即傅立叶级数的表达形式。

3.【卷积滤波操作的“核心理论基础”】

卷积定理 (The Convolution Theorem)：这是所有知识点的“连接枢纽”。

  • 内容：在时域上对两个信号（x[n] 和 h[n]）先进行卷积，再进行傅立叶变换，其结果等价于，在对这两个时域信号各自先进行傅里叶变换（X(ω) 和 H(ω)），再进行进行乘积。
  • 公式：

时域卷积 ⟺ 频域乘积：

$$\mathcal{F}{f(t) * g(t)} = F(\omega) \cdot G(\omega)$$

  • 意义：它告诉我们，一个看似复杂的时域运算过程（卷积），其最终效果可以在频域被一个极其简单的运算过程（乘法）来精确预测。**这使得我们能够通过分析 h[n] 的频域特性 H(ω)，来预知滤波的结果。**这样就对应了前文说的，可以通过分析滤波器在频域上的表达式，确定该滤波器的滤波效果。

4.【实例分析：5点移动平均滤波器 (Case Study)】

目标 (Goal)：实现一个低通滤波器，对信号进行平滑处理。

定义工具 (Define the Tool in Time Domain)：

  • 我们选择了一个简单的“取平均”操作，其对应的滤波器核为 h[n] = [1/5, 1/5, 1/5, 1/5, 1/5]。

执行操作 (Perform the Action in Time Domain)：

  • 通过卷积 y[n] = x[n] * h[n]，得到平滑后的输出信号。

分析与证明 (Analyze via Frequency Domain)：

  • 提问：凭什么说这个操作就是低通滤波？
  • 解码：对 h[n] 进行傅里叶变换，得到其频率响应 H(ω)。
  • 看图说话：H(ω) 的图像呈现出一个巨大的主瓣和多个衰减的旁瓣。
    • 主瓣：在低频区 (ω 接近0) 响应接近1，意味着低频信号能很好地通过。
    • 衰减趋势：主瓣总体趋势是下降的，并在特定频率点（零点）降为0，意味着高频信号被抑制甚至完全滤除。
    • 旁瓣：图像不是单调递减，说明这个简单的滤波器并不完美，会对某些高频有微弱的通过效应。

3. Q&A

Q1: 为什么只用傅立叶变换实现理想滤波？

之前的傅立叶级数不是可以把任意信号分解成无数个三角函数的和吗，那我直接丢掉那些高频的三角函数，把剩下的融合不就去除高频信号了吗?为什么不这么做呢

A1: 这里有三个问题，1. 现实对实时处理存在需求，但傅立叶变换需要完整的一段信号。2. 工程上的实现问题，如果直接按照阈值，删除掉高频数据，会产生“吉布斯”效应，两端会非常的不稳定，用有限个三角函数拟合一段信号，边缘处肯定会震荡。

2. 小波变换

1. 核心思想：为什么需要小波变换？

传统的傅立叶变换有局限性，能把信号写成时域或频域的形式，但它的核心缺陷在于缺乏时间局部性。它能告诉你一段信号中包含哪些频率，但无法告诉你这些频率是在什么时候出现的。

小波变换 (Wavelet Transform) 的诞生就是为了解决这个问题。它提供了一种时频分析 (Time-Frequency Analysis) 的能力，可以同时揭示：

  • 信号中包含哪些频率成分。
  • 这些频率成分出现的时间位置。

而这两者可以通过计算原始信号和压缩（体现频率）与位移（体现时间位置）后的小波的相似度（公式中的 信号乘积的积分）来体现，也就是最终想要计算的小波系数$CWT_{x}(a, b)$。

2. 理论基础：小波变换的数学公式

连续小波变换 (CWT)

这是小波变换最根本的数学定义，它将一维信号映射到一个二维的“时”“频”平面。

$$CWT_{x}(a, b) = \int_{-\infty}^{\infty} x(t) \psi_{a,b}^{*}(t) dt$$

$CWT_{x}(a, b)$是小波系数，是我们最终想要的东西。

这个公式的核心是被称为“子小波”的函数族：

$$\psi_{a,b}(t) = \frac{1}{\sqrt{a}} \psi\left(\frac{t-b}{a}\right)$$

公式解读：

$x(t)$: 原始信号。

$\psi(t)$: 母小波，是后续所有分析的基础模板。

$a$: 尺度参数。控制小波的“胖瘦”，对应频率分析。

$a$ 小 → 小波窄 → 频率高 → 捕捉细节。

$a$ 大 → 小波宽 → 频率低 → 捕捉趋势。

$b$: 平移参数。控制小波在时间轴上的位置，对应时间分析。

$CWT_{x}(a, b)$: 小波系数，表示信号在时间点 $b$、尺度 $a$ 上的特征强度。

离散小波变换 (DWT)

CWT在计算上是冗余且低效的。DWT是其更高效的实用版本，通过对尺度 $a$和平移$b$ 进行离散化（通常是二进采样）来实现。

离散化后的小波函数族为：

$$\psi_{j,k}(t) = 2^{-j/2} \psi(2^{-j}t - k)$$

参数解读：

$j$: 离散的尺度级别 (Level)，对应 $a$。

$k$: 离散的时间位置 (Position)，对应 $b$。

3. 理论到实践的桥梁：多分辨率分析 (MRA)

直接计算DWT的积分公式依然非常困难。多分辨率分析 (Multiresolution Analysis, MRA) 理论是小波变换能够高效实现的基石。它揭示了一个深刻的事实：复杂的积分变换可以等价地通过一个简单的滤波器组和迭代的降采样信号进行卷积计算来迭代实现。

MRA的核心思想在于用不同“分辨率”的镜头看信号。一个信号可以在一系列具有不同分辨率的函数空间中被观察。这就像用一系列分辨率不同的相机镜头去看一个物体。

MRA理论引入了两个核心函数：

3.1 尺度函数 (Scaling Function)

$$\phi(t)$$

角色: 趋势捕捉者，近似器。被称为**“父小波”**。

功能: 捕捉信号在某个尺度下的平滑近似 (Approximation)。

对应: 低通滤波器 (Low-pass Filter)，能计算出该尺度函数唯一对应的滤波器。

公式：$$\phi(t) = \sqrt{2} \sum_{k} h[k] \cdot \phi(2t - k)$$（双尺度关系方程 ），其中低通滤波器 h[k] 由尺度函数唯一确定，这个公式之中，$\phi(2t)$代表对函数$\phi(t)$ 在时间轴上的压缩 (Compression)，使其变窄。这是一种尺度变换，并非下采样。这个公式是负责，计算出来特定的滤波器的。

3.2 小波函数 (Wavelet Function)

$$\psi(t)$$

角色: 细节捕捉者，差异检测器。被称为**“母小波”**。

功能: 捕捉从一个尺度到下一个更精细尺度之间丢失的细节 (Detail)。

对应: 高通滤波器 (High-pass Filter)。

4. 高效实现：快速小波变换 (FWT) 算法（工程实践）

即“卷积+下采样”过程，也叫滤波器组 (Filter Bank) 算法。它完全绕开了积分计算。

4.1 分解 (Decomposition) 过程

对于一个信号（我们称之为$A_0$），进行一级分解的步骤如下：

  1. 卷积：
    • 将信号 $A_0$与**低通滤波器h** 进行卷积，得到低频成分。
    • 将信号 $A_0$ 与高通滤波器 `` 进行卷积，得到高频成分。
  2. 下采样 (Downsampling)：
    • 将上述两个卷积结果的长度减半（例如，隔一个点丢一个点），以去除冗余。
    • 从低通滤波路径得到的结果，称为近似系数 $A_1$。
    • 从高通滤波路径得到的结果，称为细节系数 $D_1$。

4.2 迭代过程

DWT的核心是迭代。上述分解过程会不断地在新的近似系数上重复进行。

  • 第1级: 对 $A_0$` (原始信号) 操作，得到 $A_1$ 和 $D_1$。
  • 第2级: 对$A_1$ 操作，得到 $A_2$和 $D_2$。
  • 第3级: 对 $A_2$ 操作，得到 $A_3$ 和 $D_3$。
  • …以此类推。

最终，一个原始信号会被分解成：$[A_n, D_n, D_{n-1}, …, D_2, D_1]$。这个信号的组合正好也是二维的，用工程的“卷积-下采样”的方法就是实现了计算我们想要的**“小波系数**$CWT_{x}(a, b)$”，每一条分解后的信号（卷积结果）就代表了固定了缩放系数 a但平移系数 b 可以自由选择的一维函数/信号。

4.3 重构 (Reconstruction)

这个过程是完全可逆的。通过上采样 (Upsampling) 和一对重构滤波器 ($h’$ 和 $g’$)，可以从分解后的系数完美地还原出原始信号。（因为这部分是迭代着进行“卷积-下采样”操作，所以保留着下采样之前的信息，能还原信号）

5. 工程应用

应用小波变换进行滤波的流程

  1. 选择工具: 根据任务需求，从众多小波家族中选择一个合适的母小波 (e.g., ‘db4’, ‘sym8’, ‘haar’)。这个选择立刻确定了你将要使用的滤波器 h 和 g。

  2. 执行分析: 使用确定的 h 和 g，对信号进行多级“卷积+下采样”，得到一系列小波系数 [A_n, D_n, …, D_1]。

  3. 处理系数: 对得到的小波系数进行有针对性的操作，例如：

  • 去噪: 对细节系数 D_j 进行阈值处理，去除小的系数。
  • 压缩: 丢弃大量接近零的系数。
  • 特征提取: 计算每个系数子序列的能量、方差等统计量。
  1. 信号重构: 如果需要，使用处理后的系数和重构滤波器 h', g'，通过“上采样+卷积”的逆过程，还原出信号。

Q&A

Q1： 小波变换和傅立叶变换有什么关系？

我感觉傅立叶变换是同一个事物的不同表达方式，就像正方形写成长和宽的数学公式，也可以直接画出图像。而小波变换后不再是原始信号的准确表达，是混合新的东西后的一个新的值，是原始信号和压缩和平移后的母小波的相似度，是一个全新的东西，是小波系数函数。

Q2: 什么是映射？

A2: 在数学中，“映射”(Mapping) 是一个非常基础和广泛的概念，它与“函数”(Function) 或“变换”(Transformation) 几乎是同义词。它的定义是：

一个从集合 A 到集合 B 的映射，是一个规则，它将集合 A 中的每一个元素，都唯一地对应到集合 B 中的一个元素。

这个定义里，最关键的是**“输入 -> 规则 -> 输出”**这个对应关系。它并不关心这个“规则”本身是简单的代数运算、复杂的积分，还是一个黑箱。

例子1：简单的函数 $f(x) = x^2$是一个映射。它将一个实数$x$(来自输入集合 **R**) 通过“平方”这个规则，映射到一个非负实数$y$` (来自输出集合 R≥0)。

例子2：DL中的MLP 一个多层感知机 (MLP) 也是一个映射。它将一个n维向量 (来自输入空间 $\mathbb{R}^n$) 通过一系列“加权求和+激活函数”的规则，映射到一个m维向量 (来自输出空间 $\mathbb{R}^m$`)。

Q3: 为什么“卷积+下采样”能计算出小波系数？

A3: 因为这个算法巧妙地将理论上的积分（相似度计算）*和*尺度伸缩，等价地转换成了工程上极其高效的离散卷积和迭代操作。具体来说，“卷积”能代替“积分”来计算相似度，这解释了如何处理平移维度 b 或 k；“迭代+下采样”能代替“尺度伸缩”，这解释了如何处理尺度维度 a 或 j**。
